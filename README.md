# ⚡ Hermes AI Assistant: Персональный ИИ-ассистент с памятью, скиллами и веб-поиском

Многофункциональный автономный ИИ-помощник для Telegram, построенный по принципам **Hermes Agent** (агентный цикл ReAct, память, динамические скиллы, веб-поиск и работа с бесплатными моделями OpenRouter). В бота также интегрирован полноценный модуль **тренажера продаж**.

---

## 🌟 Возможности Hermes

1. **🧠 Долговременная память**:
   - Автоматическое извлечение и запоминание фактов о вас (имя, профессия, стек технологий, цели, заметки).
   - Команды ручного управления: `/memory`, `/remember <факт>`, `/forget <id>`.
   - Интерактивный редактор памяти прямо в Telegram-чате (с кнопками удаления).

2. **⚡ Создание и управление скиллами**:
   - Создание новых скиллов прямо из обычного диалога (например: *«Создай скилл 'Аналитик крипты', который кратко анализирует монеты и дает риски»*).
   - Включение и выключение скиллов через инлайн-меню `/skills`.
   - Встроенные скиллы:
     - 🎯 `sales_coach` — эксперт по преодолению возражений и переговорам.
     - 🔍 `web_researcher` — глубокий поиск актуальных фактов и новостей со ссылками.
     - 💻 `code_assistant` — senior разработчик ПО для написания чистого кода и архитектуры.

3. **🔍 Поиск информации в реальном времени**:
   - Бесплатный веб-поиск через DuckDuckGo (`ddgs`) без необходимости платных API-ключей.
   - Извлечение содержимого веб-страниц по URL (`fetch_webpage`).
   - Автоматический вызов поиска агентом при вопросах о свежих событиях, новостях, курсах валют.

4. **🤖 Бесплатные модели OpenRouter**:
   - Работает на бесплатных моделях (`openrouter/free`, `qwen/qwen3.8-27b:free`, `google/gemma-4-31b-it:free`, `nvidia/nemotron-3.5-lightning:free` и др.).
   - Автоматический fallback (переключение на резервную модель при лимитах 429 или перегрузке).
   - Выбор модели на лету через команду `/model`.

5. **🎯 Встроенный тренажер возражений (Sales Coach)**:
   - 10 ключевых возражений и 50 эталонных приемов отработки.
   - Алгоритм интервальных повторений SM-2.

## 🛠 Настройка и запуск

### 1. Переменные окружения (`.env`)
Создайте или отредактируйте файл `.env`:
```env
BOT_TOKEN="ваш_токен_telegram_бота"
openroute_api="sk-or-v1-ваш_ключ_openrouter"
PORT=10000
```

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Запуск бота
```bash
python main.py
```

Веб-сервер для healthcheck запустится на порту 10000, а бот подключится к Telegram через polling.

## 💬 Команды бота

- `/start` или `/menu` — главное меню и панель быстрого доступа
- `/help` — подробная справка по возможностям
- `/memory` — просмотр и удаление фактов из долговременной памяти
- `/remember <факт>` — вручную сохранить факт в память
- `/forget <id>` — удалить воспоминание по ID
- `/skills` — меню управления активными скиллами
- `/newskill` — справка по созданию нового скилла
- `/model` — выбор активной модели ИИ (OpenRouter Free)
- `/search <запрос>` — принудительный поиск в сети
- `/clear` — очистить контекст текущего диалога
