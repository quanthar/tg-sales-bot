# 🤖 Telegram-тренажер возражений в продажах (10 по 5)

Интеллектуальный Telegram-бот для тренировки 10 ключевых возражений и 50 эталонных ответов. Разработан на основе методологий когнитивной науки: **Active Recall** (активное вспоминание), **Spaced Repetition** (интервальные повторения SM-2) и **блочного фреймворка** отработки возражений.

---

## 🎯 4 категории возражений

Все 10 возражений разделены на 4 логические группы:
1. 💰 **Деньги и Бюджет** (*«Дорого»*, *«Нет бюджета / Нет денег»*)
2. 🚫 **Отказ и Нет интереса** (*«Нам не надо»*, *«Не заинтересовало»*)
3. ⏳ **Оттягивание и Слив** (*«Я подумаю»*, *«Вышлите на почту»*, *«Еще не смотрел»*, *«Нет времени»*)
4. 🤝 **Конкуренты и ЛПР** (*«Работаем с другими»*, *«Решает директор / офис»*)

Каждое возражение содержит **5 готовых вариантов ответа** с разной тактикой (качество, интрига, окупаемость, возврат ответственности, игра с тщеславием и др.).

---

## 🚀 Быстрый запуск локально

1. Убедитесь, что установлены зависимости:
```bash
pip install -r requirements.txt
```

2. Запустите бота:
```bash
python main.py
```

Веб-сервер запустится на `http://localhost:10000`, а бот подключится к Telegram.

---

## ☁️ Деплой на Render.com (Бесплатно 24/7)

Проект полностью оптимизирован для бесплатного тарифа **Render Free Web Service**:
- В бот встроен веб-сервер `aiohttp`, отвечающий на эндпоинт `/health`.
- Входящие пинги не дают сервису заснуть, а 750 бесплатных часов в месяц покрывают работу 24/7.

### Пошаговая инструкция:
1. Загрузите код бота в ваш GitHub-репозиторий (публичный или приватный).
2. Зайдите в [Render Dashboard](https://dashboard.render.com).
3. Нажмите **New +** $\rightarrow$ **Web Service**.
4. Подключите ваш GitHub-репозиторий.
5. Настройки сервиса:
   - **Environment**: `Python 3`
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `python main.py`
   - **Instance Type**: `Free`
6. В разделе **Environment Variables** добавьте:
   - `BOT_TOKEN` = `ваш_токен_бота`
   - `PORT` = `10000`
7. Нажмите **Create Web Service**. Через 1–2 минуты ваш бот запустится и получит адрес вида:  
   `https://sales-objection-bot.onrender.com`

## ⏱ Настройка бесплатного пингования (раз в 10 минут)

Чтобы бесплатный сервис на Render не уходил в спящий режим через 15 минут неактивности:

1. Перейдите на бесплатный сервис [cron-job.org](https://cron-job.org).
2. Зарегистрируйтесь (только email и пароль, **без карт**).
3. Нажмите **«Create Cronjob»**:
   - **Title**: `Ping Telegram Bot`
   - **URL**: `https://<ваше-имя-на-render>.onrender.com/health`
   - **Execution schedule**: выберите **«Every 10 minutes»** (или «Every 9 minutes»).
4. Нажмите **Create**.
5. Теперь сервис будет отправлять легкий `GET`-запрос каждые 10 минут, и бот на Render будет всегда бодрствовать и мгновенно отвечать пользователям в Telegram!

## 📂 Структура файлов проекта

- `main.py` — Точка входа: запускает бота и веб-сервер.
- `src/handlers.py` — Обработчики диалогов, карточек, категорий, шпаргалки и системы Active Recall.
- `src/keyboards.py` — Интерактивные inline-клавиатуры бота.
- `src/database.py` — База данных SQLite и алгоритм интервального повторения SM-2.
- `src/web_server.py` — Легковесный веб-сервер для поддержания активности на Render.
- `src/config.py` — Конфигурация и загрузка переменных окружения.
- `data/objections.json` — Структурированная база 10 возражений и 50 ответов.
- `Возражения_по_категориям.md` — Шпаргалка в текстовом виде.
- `render.yaml` — Конфигурация автоматического деплоя на Render.
- `Dockerfile` — Докер-образ для альтернативного запуска.
